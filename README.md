# 🔱 小六壬宇宙 (Xiao-Liuren Universe)

![Xiao-Liuren Universe](https://img.shields.io/badge/Status-Unified-blueviolet)
![License](https://img.shields.io/badge/License-MIT-green)

> 「一元復始，六卦乾坤。跨越語言，通向預測之巔。」

## 🌌 願景 (Vision)
小六壬宇宙旨在將傳統術數「小六壬」與現代軟體工程結合。透過多語言 (PHP, Go, TypeScript, JavaScript, Python/Predict) 的標準化實作，提供一致、精確且高效的起卦與分析邏輯。

這是一個**技術主權**的整合，將分散的邏輯歸於一統，為未來的「小六壬即服務 (XLaaS)」打下堅實基礎。

## 📦 模組結構 (Packages)
- `packages/php/`: PHP 版本實作。
- `packages/go/`: 高性能 Go 版本實作。
- `packages/ts/`: 強型別 TypeScript 核心邏輯。
- `packages/js/`: 前端或 Node.js 輕量化 JavaScript 實作。
- `packages/predict/`: 預測核心與 AI/Python 整合邏輯。

## 🛠️ 開發準則 (Contribution Guidelines)
- **邏輯統一性**: 核心起卦公式必須跨語言一致。
- **測試驅動**: 每個語言模組應包含對應的單元測試。
- **現代化管理**: 採用 Monorepo 結構進行版本控管。

## 🖐️ 手指五行對照表 (Finger Five Elements)

```
          木 木 土        ← 食指 (Index)
          火 土 水        ← 中指 (Middle)
          土 金 金        ← 無名指 (Ring)
```
